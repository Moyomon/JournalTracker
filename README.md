# Journal Tracker [BETA] - ゲーム翻訳ツール

ゲーム画面の指定した範囲を見張り、新しいセリフが出るたびに自動で日本語に翻訳するツールです。

[最新版をダウンロード](https://github.com/Moyomon/JournalTracker/releases/latest/download/JournalTracker.zip)  
※初回起動時のみファイルを展開するため時間がかかります。

## ✨ 主な機能

*   **範囲を選ぶだけで自動翻訳**  
    字幕やセリフの変化を自動で検知し、新しい文だけを翻訳します。キーを押す必要はありません。
    同じ文や表示途中の文は送らないので、翻訳の回数も最小限に抑えられます。 
    
*   **翻訳結果の文字サイズ変更**  
    モニター環境や好みに合わせて、翻訳結果の文字の大きさを自由に変えられます。
    
*   **ストーリーを見返せる翻訳ログ**  
    翻訳結果はログとして残ります。読み飛ばしてしまったセリフも、あとから確認できます。

## 🛠 使い方
1.  設定画面から Google Apps Script（GAS）のデプロイIDを入力します。
2.  ［範囲選択］で翻訳したい範囲を指定すると、自動翻訳が始まります。
3.  ［停止］／［再開］でいつでも止められます。

**コツ**：範囲は字幕やセリフ欄の帯だけに絞ってください。広く取ると、文字の変化を検知しにくくなります。

## ⚠️ ご注意
*   **BETA版**です。背景が激しく動く場面では、短いセリフを取りこぼすことがあります。
*   GASの翻訳は1日5,000回までです。上限やエラーで翻訳が続けて失敗すると、自動翻訳は止まります。
